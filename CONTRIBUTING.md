# Contributing

Corrections and clearer explanations are welcome.

- Cite an official or primary source for technical changes.
- Keep notes aligned with a published blueprint objective.
- Write original practice scenarios and explanations.
- Do not submit recalled exam questions, dumps, proprietary course content, or copyrighted screenshots.
- Distinguish stable concepts from model-specific or release-specific facts.
- Use plain Markdown and relative links for repository content.
